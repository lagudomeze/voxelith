## 编号

用 `REQ-xxx`。旧项目的 `R1`–`R117` 是「规则」不是需求，`R<n>` 永久留给 `legacy` 引用，新体系不占用它。

## 条目格式

```markdown
### REQ-001 <一句话标题>
- 需求：<谁，在什么情况下，能做什么 / 系统必须保证什么>
- 判定标准：<怎么算满足，可验证>
- 来源：<原始讨论位置，或某次确认（带日期），或 `legacy` 文档路径>
- 不做：<明确排除的范围，可省略>
```
