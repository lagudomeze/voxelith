# 需求清单

**来源**：从重构前项目 `legacy`（提交 `973ddd5`）的 22 篇文档与工作日志提炼，每条都带出处。这些是你上一轮已经定过的东西——不是新提议。

**收录口径**：重复的合并；**已被取代的旧机制不收**（列在下面"不收录"）；**互相冲突的一律不收**（在对话里定，定了再补进来）。

**不收录**：旧的四阶段伤害管线、独立抵抗组件与判定层、`Health` 组件、`DamageRequest`、伤害类型枚举、状态父子实体 + 回调、最终值回写消息、显式字段版属性表、成长链（经验/升级/加点）。

**格式**：`REQ-xxx` 只增不改；被推翻的移到[第八节](#八明确不做)并注明日期。

**时间口径**：全项目统一用**秒**。内容里写"每 X 秒回复 Y""冷却 Z 秒""状态持续 N 秒"，不使用"回合"（2026-10-09 定）。
