# 质量与非功能

细则层。编号 `QL-xx`。这些不是玩法，但都是硬要求。

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| QL-01 | 游戏逻辑必须能在没有渲染、没有文件系统的环境里运行与测试 | 逻辑测试不需要装配渲染与素材即可跑通 | layers §9 |
| QL-02 | 运行中的游戏必须能被外部程序读到世界状态：不重启、不改代码 | 外部进程能查询运行中世界的组件与资源 | debugging §0 |
| QL-03 | 人要有世界浏览通道：查看并就地修改，与外部程序看的是同一份状态 | 人所见与外部查询结果一致 | debugging §0、§4 |
| QL-04 | 内容算不出来时按 0 处理，绝不崩溃 | 引用不存在的资源时游戏继续运行，且该效果为 0 | combat-design §3.1 |
| QL-05 | **不要求复现过程**：只需要把发生过的事情记录清楚（战斗日志）；随机只允许出现在判定处 | 战斗过程能从日志读懂；判定之外没有随机 | 2026-10-09 修订 |
| QL-06 | 随机源**可替换**（供测试注入固定序列） | 测试里能对带随机的逻辑做断言 | 2026-10-09 定 |
