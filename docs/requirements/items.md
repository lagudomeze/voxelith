# 物品与装备

细则层。编号 `IT-xx`。这一节目前很薄——只记已经定下来的。

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| IT-01 | 有**装备栏**，按**肢体部位**划分 | 每个部位对应一个装备位，能穿上与取下 | 2026-10-09 定 |
| IT-02 | 有**物品栏**（背包） | 物品能被拾取、存放、取出使用 | 2026-10-09 定 |
| IT-03 | 装备会改变角色的数值——例如**增加挖掘距离** | 换一件装备后，可达的挖掘 / 放置距离随之变化 | 2026-10-09 定 |
| IT-04 | 工具（手部装备）提供**挖掘力**：挖掘速度由工具决定，不共用战斗的强度 | 换上更好的镐，挖掘变快；换武器不影响挖掘 | 2026-10-09 定 |
