# 系统与数值

细则层。编号 `SY-xx`。数字都是**当前取值**，可在数值阶段调整。

## 资源与属性

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-01 | **血量与精力**是每个角色都有的**基本资源**；**法力（mana）**等按角色配置，不保证人人都有 | 某个角色可以没有法力，但一定有血量与精力 | 2026-10-09 修订 |
| SY-02 | 每种资源有上限与回复速度，都由内容配置 | 改配置能改变上限与回复速度，不改代码 | combat-design §13 |
| SY-03 | 六项标准属性：力量、敏捷、体质、感知、**魔力**、意志 | 属性面板上出现且只出现这六项 | 2026-10-09 修订 |
| SY-04 | 数值全程实数、不取整，包含内容文件里的数值 | 属性与资源都能带小数 | OPEN-QUESTIONS Q25 |
| SY-05 | 数值变化必须可追溯："谁把血量改了"永远答得出来 | 资源变化显示在战斗日志里 | layers §3 R13、R56 |
| SY-06 | 资源要有模型多样性：小幅回复、不回靠赚、越高越糟、动态衰减、挨打才涨、硬上限 | 这些模型都能配置出来，角色手感随之不同 | numbers §4.5 |
| SY-07 | 冷却与速度分离：加速不缩短冷却 | 加速让同样时间内动作更多，但不让冷却变快 | numbers §4.6 |
| SY-08 | 减速收益递减，且永远不能把速度变成 0 或负数 | 任意减速量下速度恒为正 | numbers §4.6 |
| SY-30 | 之后还会有只属于某些角色的**专属资源**（例如悖论、均衡、仇恨） | 这些资源只出现在拥有它的角色身上，不是人人都有 | 2026-10-09 定 |
| SY-31 | **资源就是要扣的量**：技能的消耗落在这里；**冲刺**这类基础行动也扣精力 | 任何技能的消耗都能落到某条资源上；冲刺时精力下降 | 2026-10-09 修订 |
| SY-32 | 六项属性决定**法术强度**，并**影响各条资源的基本值** | 属性变化后，法术强度与资源上限随之变化 | 2026-10-09 定 |
| SY-33 | 属性变化有三个来源：**升级加点**、**装备**、**增益 / 减益**；装备与增益带来的提升，在**移除后立刻失效** | 卸下装备后属性立刻回落到原值 | 2026-10-09 定 |
| SY-34 | 基本资源的判据是「它服务于人人都有的能力」（血量＝活着、精力＝基本行动）；只服务于特定角色的资源按角色配置 | 新增一条资源时，能用这条判据说清它是不是人人都有的 | 2026-10-09 定 |
| SY-35 | 有**等级与经验**：经验累积到阈值升级；升级发**两套互相独立的点**——**属性点**加六项属性，**技能点**点开技能 | 升级后既能加点也能点技能；两套点不能互相挪用 | 2026-10-09 修订 |
| SY-36 | 书与师傅只是「领进门」：它们给的是技能**起点**，不是终点；后面的形态靠使用与投入长出来 | 一本书能解锁技能，但不能直接把它点满 | 2026-10-09 定 |
| SY-37 | **技能会随使用演进**：同一个技能在不同阶段是不同的东西——例如「格挡」起初是"花精力、一段时间内提升防御"的增益，之后变成"概率免除扣血"的被动，最后点出反制能力 | 同一个技能在不同阶段表现不同，而不是变成另一个技能 | 2026-10-09 定 |
| SY-38 | 经验来源是**多来源**：击杀、探索、完成目标都算；各自给多少属数值设计 | 三类行为都能得到经验 | 2026-10-09 定 |

## 对抗与判定

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-09 | 随机只出现在**判定**这一处（不散落在别处）；但**不要求"从种子重放战斗"**——发生过什么记进战斗日志就够了 | 判定之外没有随机；战斗过程能从日志读懂 | 2026-10-09 修订 |
| SY-39 | 持续性效果与区域效果**每一跳都各自判定一次**；每跳的攻方取**施加时锁定的强度**（施法者之后变弱或死去都不影响）；某一跳失败就是那一跳完全不生效 | 施法者死后毒仍在；被抵抗的那一跳不扣血 | 2026-10-09 修订 |
| SY-40 | **反制强度复用属性**：= 属性（按类型：力量 / 魔力 / 感知）+ 技能威力 + 修正，与其它技能的强度是同一套算法 | 换更强的属性或技能，反制更有把握 | 2026-10-09 定 |
| SY-41 | **打断 = 两个行动的强度比大小**：我这次反制行动的强度 vs 它那次行动**此刻**的强度 | 把它削弱了，它更好打断；它用大招，则更难打断 | 2026-10-09 定 |
| SY-42 | **反制的重心是「效果」（取消那次行动），不是扣血**；反制技能带的原始伤害通常很小，甚至没有 | 一条几乎不造成原始伤害的反制技能依然有价值 | 2026-10-09 定 |
| SY-43 | 反制**不退还被反制方已付的代价**（资源与冷却已扣），所以反制的收益就是"这一次效果不落地" | 被反制后它的资源白花、事情没成 | 2026-10-09 定 |
| SY-44 | **没有独立的"格挡"减免路径**：格挡落地成「提升护甲值与坚韧度」的效果（由装备或技能提供），复用护甲那一条路 | 盾的数值表现为更高的护甲与坚韧度；护甲分割照常 | 2026-10-09 修订 |
| SY-46 | 护甲是**分割**机制，只有**坚韧度**能压小"绕过的那部分"；**坚韧度必须有上限**，否则可以完全免伤 | 坚韧度越高，绕过护甲的原始伤害越少；任何情况下都不会因为堆护甲而完全免伤 | 2026-10-09 定 |
| SY-47 | 三个词各管一段：**强度**（出手力度，用于对抗，与目标无关）→ **原始伤害**（减免前，有类别）→ **扣血**（减免后真正扣掉的数，就是屏幕上跳的数字） | 文档里「伤害」不再指减免前的量 | 2026-10-09 定 |
| SY-48 | 原始伤害有**少数几类固定类别**（当前取值：物理、火、冰、雷）；类别是**引擎能力**，加一类要改代码 | 结算与界面能按类别区分 | 2026-10-09 定 |
| SY-49 | **护甲只作用于物理类**原始伤害，**抗性只作用于元素类**；一击只走一条路，**不叠加** | 同一击不会既过护甲又过抗性 | 2026-10-09 定 |
| SY-45 | 法术**不做"掷骰命中"**：够不够得着、躲不躲得开，都由位置决定 | 躲开飞来的法术靠走位，不靠运气 | 2026-10-09 定 |
| SY-10 | 命中与豁免围绕 50% 对称：每点优势换来固定的百分点，差值到一定程度即必中 / 必失 | 攻防相差到阈值时到达必中 / 必失边界 | numbers §4.3 |
| SY-11 | 一次对抗成功的强度可以被后续效果引用（"强多少就打多少"） | 效果里引用的强度等于该次对抗算出的量 | combat-design §5 |
| SY-12 | 护甲是确定性的、不掷骰 | 相同输入下减免结果完全相同 | numbers §4.2 |
| SY-13 | 护甲**只分割原始伤害**：大来伤里总有一部分直接穿过去 | 原始伤害越大，被护甲吃掉的占比越低 | numbers §4.2 |
| SY-14 | 抗性有上下限，下限是负的（即易伤） | 抗性可以被压到负值，表现为扣血更多 | numbers §4.1 |
| SY-15 | 穿透只对正抗性有效，永远不能把抗性变成易伤 | 对负抗性用穿透不产生额外收益 | numbers §4.1 |
| SY-16 | 凡理论上可能超过 100% 的量（抗性上限、持续时间上限、免疫率…）必须有硬上限 | 这类量恒不超过设定上限 | numbers §2.1 |
| SY-17 | 治疗与扣血走同一条通路，只靠正负号区分 | 两者写入路径相同 | combat.md R51 |

## 状态

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-18 | 状态可被免疫、可被净化，且净化可以只针对指定状态 | 免疫目标不中状态；净化只清指定状态 | combat-mechanics §4.7 |
| SY-19 | 状态的叠加与刷新方式明确：可叠加的叠层、可刷新的刷新、"不可刷新"的不能被延长 | 重复施加不可刷新的减益不会延长其剩余时长 | combat-mechanics §4.7、TODO.md:1541 |
| SY-20 | 状态到期不留残留，也不需要一个"清理"动作 | 到期后属性回到没有该状态时的值 | OPEN-QUESTIONS Q19 |
| SY-21 | 状态能拦下带指定标签的技能 | 处于该状态的实体无法释放被拦标签的技能 | combat-design §4.1 |
| SY-22 | 状态时长有保底、刷新不缩短；抵抗与否由判定随机决定 | 成功的施加至少持续一个最小秒数 | numbers §4.4 |
| SY-23 | 存在"可豁免"与"必然生效"两类状态，且是内容的显式选择 | 每个状态在内容里标明属于哪一类 | numbers §4.4 |
| SY-24 | 重复施加同一状态有明确后果：持续性效果不因重复而爆炸，增益类不被更弱的效果顶掉 | 连点同一个持续性技能不会使总扣血指数增长 | numbers §4.7 |
| SY-25 | 控制类效果由属性决定成功率（"力量越高越容易眩晕"），不是由技能等级决定 | 同一条控制技能对不同属性目标的成功率不同 | TODO.md:1537 |

## 成长与曲线

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-26 | 成长曲线可配置：锚点是内容里的显式字段，锚点处取值精确命中 | 下 / 上锚点取值分别等于设定的两端 | numbers §2.1 |
| SY-27 | 数值压缩要能让玩家心算：每一段都是整数兑换率，可展示、可规划 | 任意段都能用一句话说明兑换率 | numbers §3 |
| SY-28 | 面板上看到的数字线性增长（投入有反馈），而真正进公式的有效值被压平 | 显示值随投入线性增长，有效值增速递减 | numbers §3 |
| SY-29 | 成长曲线不在每条技能里各写一遍内联公式 | 技能定义里不出现内联线性公式 | combat-design §3.1 |
