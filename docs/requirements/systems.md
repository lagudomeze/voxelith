# 系统与数值

细则层。编号 `SY-xx`。数字都是**当前取值**，可在数值阶段调整。

## 资源与属性

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-01 | **血量**是每个角色都有的资源；**法力（mana）、精力**等按角色配置，不保证人人都有 | 某个角色可以没有法力 | 2026-10-09 修订 |
| SY-02 | 每种资源有上限与回复速度，都由内容配置 | 改配置能改变上限与回复速度，不改代码 | combat-design §13 |
| SY-03 | 六项标准属性：力量、敏捷、体质、感知、**魔力**、意志 | 属性面板上出现且只出现这六项 | 2026-10-09 修订 |
| SY-04 | 数值全程实数、不取整，包含内容文件里的数值 | 属性与资源都能带小数 | OPEN-QUESTIONS Q25 |
| SY-05 | 数值变化必须可追溯："谁把血量改了"永远答得出来 | 资源变化显示在战斗日志里 | layers §3 R13、R56 |
| SY-06 | 资源要有模型多样性：小幅回复、不回靠赚、越高越糟、动态衰减、挨打才涨、硬上限 | 这些模型都能配置出来，角色手感随之不同 | numbers §4.5 |
| SY-07 | 冷却与速度分离：加速不缩短冷却 | 加速让同样时间内动作更多，但不让冷却变快 | numbers §4.6 |
| SY-08 | 减速收益递减，且永远不能把速度变成 0 或负数 | 任意减速量下速度恒为正 | numbers §4.6 |
| SY-30 | 之后还会有只属于某些角色的**专属资源**（例如悖论、均衡、仇恨） | 这些资源只出现在拥有它的角色身上，不是人人都有 | 2026-10-09 定 |
| SY-31 | **资源就是"释放技能时要扣的量"**：每个技能的消耗 = 某条资源 + 数量 | 任何技能的消耗都能落到某一条资源上 | 2026-10-09 定 |
| SY-32 | 六项属性决定**法术强度**，并**影响各条资源的基本值** | 属性变化后，法术强度与资源上限随之变化 | 2026-10-09 定 |
| SY-33 | 属性变化有三个来源：**升级加点**、**装备**、**增益 / 减益**；装备与增益带来的提升，在**移除后立刻失效** | 卸下装备后属性立刻回落到原值 | 2026-10-09 定 |

## 对抗与判定

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-09 | 同一份输入必然得到同一个结果：随机只发生在一个点，且带种子 | 同种子重放得到逐帧一致的结果 | OPEN-QUESTIONS Q22 |
| SY-10 | 命中与豁免围绕 50% 对称：每点优势换来固定的百分点，差值到一定程度即必中 / 必失 | 攻防相差到阈值时到达必中 / 必失边界 | numbers §4.3 |
| SY-11 | 一次对抗成功的强度可以被后续效果引用（"强多少就打多少"） | 效果里引用的强度等于该次对抗算出的量 | combat-design §5 |
| SY-12 | 护甲是确定性的、不掷骰 | 相同输入下减伤结果完全相同 | numbers §4.2 |
| SY-13 | 护甲挡不住大伤害的全部：一部分伤害直接穿过去 | 伤害越大，被护甲吃掉的占比越低 | numbers §4.2 |
| SY-14 | 抗性有上下限，下限是负的（即易伤） | 抗性可以被压到负值，表现为受到更多伤害 | numbers §4.1 |
| SY-15 | 穿透只对正抗性有效，永远不能把抗性变成易伤 | 对负抗性用穿透不产生额外收益 | numbers §4.1 |
| SY-16 | 凡理论上可能超过 100% 的量（抗性上限、持续时间上限、免疫率…）必须有硬上限 | 这类量恒不超过设定上限 | numbers §2.1 |
| SY-17 | 治疗与伤害走同一条通路，只靠正负区分 | 两者写入路径相同 | combat.md R51 |

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| SY-18 | 状态可被免疫、可被净化，且净化可以只针对指定状态 | 免疫目标不中状态；净化只清指定状态 | combat-mechanics §4.7 |
| SY-19 | 状态的叠加与刷新方式明确：可叠加的叠层、可刷新的刷新、"不可刷新"的不能被延长 | 重复施加不可刷新的减益不会延长其剩余时长 | combat-mechanics §4.7、TODO.md:1541 |

| SY-22 | 状态时长有保底、刷新不缩短；抵抗与否由判定随机决定 | 成功的施加至少持续一个最小秒数 | numbers §4.4 |
| SY-23 | 存在"可豁免"与"必然生效"两类状态，且是内容的显式选择 | 每个状态在内容里标明属于哪一类 | numbers §4.4 |
