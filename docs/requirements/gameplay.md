# 核心玩法

细则层。编号 `GP-xx`。这里写"玩家要做的事与规则"，不写实现。

## 时间与节奏

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| GP-01 | 玩家不操作时，世界停在原地等输入 | 玩家空闲时推进帧，倒计时与位移都不变 | combat-design §0 |
| GP-02 | 玩家一操作（移动或施法），时间才流动；走动期间怪物照常行动 | 发出移动请求后时间必须流动 | 2026-10-09 定 |
| GP-03 | 玩家一次只做一件事：移动与技能互斥 | 任一时刻角色只在做一件事 | 2026-10-09 定 |
| GP-04 | 移动会取消当前施法（默认）；"边移动边施法"是一种要争取来的能力 | 前摇内移动，这次技能不生效 | 2026-10-09 定 |
| GP-05 | 被移动取消的技能不给回退：资源已扣、冷却照走 | 起手后撤销，代价真实 | combat-design §6.1 |
| GP-06 | 技能对玩家是三段可感知的：起手（可被打断）→ 结算（不可撤回）→ 之后的冷却（不锁移动） | 冷却期间移动不取消任何东西 | movement §8 |

## 反制、打断与意图

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| GP-07 | 敌人行动威胁到玩家时，世界暂停，并给玩家一次**出手尝试**的机会——不是保证成功 | 敌人进入起手时出现反击入口 | combat-design §6 |
| GP-08 | 反制是一次攻击：落一个带打断能力的技能，**再做一次对抗，对抗成功才打断** | 对抗失败时，敌人那次行动照常结算 | 2026-10-09 修订 |
| GP-09 | 反制窗口是"等你决定"的暂停：不做反制而做别的，就是放弃 | 窗口里做别的动作后，敌人的行动照常结算 | 2026-10-09 定 |
| GP-10 | 打断与取消不止一种，具体作用对象由各条内容自己定义 | 存在"只能断起手"与"连冷却也能取消"两类效果 | 2026-10-09 定 |
| GP-11 | **不设独立的"打算"阶段**：可观察的信息就是起手中的行动本身——敌人在起手，你就看得见它要干什么 | 不存在"行动实体还没生成时的意图"；观察到的永远是已经生成的行动 | 2026-10-09 修订 |
| GP-25 | 你针对的是敌人"那一次行动"本身，不是敌人本人；打断成功之后，附带伤害才落到敌人身上 | 打断命中后敌人仍在场，只是那一次行动消失 | 2026-10-09 定 |
| GP-26 | 技能有固定次序：**释放 → 扣掉代价（资源与冷却）→ 出现那一次行动 → 走前摇 → 到点执行效果** | 技能起手之后资源已减、冷却已走 | 2026-10-09 定 |
| GP-27 | 从释放到生效之间有一段"可以被针对"的时间，打断只发生在这里 | 那一次行动存在期间才能被打断 | 2026-10-09 定 |
| GP-28 | 同一时刻只有一个威胁悬在玩家头上；其余敌人等这个窗口空出来再出手 | 两只敌人同时具备条件时，只有一个能出手 | combat-design §6.1 |
| GP-29 | 打断成功＝那一次行动被删除；敌人下一拍可以重新决定释放技能（除已付的代价之外没有额外惩罚） | 被打断后敌人仍在场，且之后能再次出手 | 2026-10-09 定 |

## 移动

| ID | 要什么 | 判定标准 | 来源 |
| --- | --- | --- | --- |
| GP-12 | 逻辑位置是离散格子，任何时刻都不能停在格与格之间 | 采样位置永远落在合法格上 | movement §1、§8 |
| GP-13 | 移动一格一格走、中间不停顿；一直按着方向就连续走 | 连续多格移动中没有额外的停滞 | movement §6、§7 |
| GP-14 | 被挡住就停下：不自动绕路、不自动重算、不自动等 | 目标格进不去时角色停在原格 | 2026-10-09 定 |
| GP-15 | 不能走到一半折返 | 移动过程中无法改变方向 | movement §9 |
| GP-16 | 速度决定走一格要多久；地形减速改变这个时长、不改变路线 | 同一路线在减速地形上耗时更长 | movement §7 |
