# 范围：不做什么、以及为什么

细则层。编号 `SC-xx`。

**"不做"有四种，别混：**

| 类型 | 含义 |
| --- | --- |
| **与支柱冲突** | 做了会违背[设计支柱](requirements.md)——**这才是真正的"不做"** |
| **已推迟** | 不是不做，是等依赖或等优先级；将来可以翻案 |
| **被取代** | 需求还在，只是换了更简单的机制去满足 |
| **明确不抄** | 参考实现那样做有它自己的约束，抄过来是纯负担 |

被推翻或降级的需求也记在这里，注明日期，不删除。

## 与支柱冲突（真正的"不做"）

| ID | 项 | 为什么 | 来源 |

| SC-01 | 用 3D 预制网格拼装地图 | 那类素材包拼的是 GLB 几何体，我们的是体素 + 网格化，两套渲染路径完全不同：**要用它就得放弃体素系统**，而"世界是可改的"是第 3 条支柱。原话："体素是三个目标里的第 1 条，不能为了用素材把它换掉" | TODO.md:1737 |

## 已推迟（等依赖或等优先级）

| ID | 项 | 为什么现在不做 | 来源 |
| --- | --- | --- | --- |
| SC-02 | 等级、经验、加点与成长链 | 成长链**曾经实现过又被删掉**；结论是"留到有真实需求时再设计"——先把核心战斗与数值做对，不提前铺面积 | OPEN-QUESTIONS Q24 |
| SC-03 | 随机词缀 | 优先级低，**等有掉落系统再说**。（它与"战斗可复现"其实不冲突：那是生成期随机，不是结算期随机） | numbers §4.8 |
| SC-04 | "按攻击者种族的抗性"这一层 | 概念有用（"对亡灵额外伤害"），但参考实现把它做成**独立一层**、与元素抗性串行叠加，规则变复杂；**优先把元素抗性做对** | numbers §4.8 |
| SC-05 | 死亡门槛（负血继续战斗） | 需要**先有死亡 / 复活流程**才谈得上 | numbers §4.8 |
| SC-06 | A\* 寻路 | 方向键一格一格已经够用；多阶段动作是招牌机制、也是反制窗口成立的前提，**优先级排在它前面** | movement §12 |

## 被取代（需求还在，换了机制）

| ID | 旧机制 | 换成了什么、为什么 | 来源 |
| --- | --- | --- | --- |
| SC-07 | 独立的生命类型 + "血量归零事件" | 生命不再特殊：血量只是资源之一，**"哪个资源是命"是内容语义**，不该成为引擎知识。血量本身当然还在 | OPEN-QUESTIONS Q18、Q1、Q3 |
| SC-08 | 四阶段伤害管线 | 换成**一次对抗包住**：原方案要靠注册顺序排规则，组合爆炸 | combat-design §13 |
| SC-09 | 独立抵抗组件 + 数值减伤 | 抵抗改成对抗里的防守方取值，**减伤变成可配置的** | combat-design §13 |
| SC-10 | 独立判定层 | 随机收进对抗原语，**全游戏只剩一个随机点**，战斗才可复现 | combat-design §13 |
| SC-11 | 属性账本 / 显式字段属性表 | 改成键控属性：**加一条属性不改代码**（代价是丢掉编译期的穷尽检查） | combat-design §13 |
| SC-12 | 阵营与种族混在同一个标签里 | 拆成三个互不干扰的维度，"玩家也可能是亡灵"不再是特例 | combat-design §13 |

## 明确不抄（参考实现的坑）

| ID | 项 | 为什么不抄 | 来源 |
| --- | --- | --- | --- |
| SC-13 | 伤害类型树 | 参考实现有 **179 种伤害类型 + 手写复合投影器**；我们的伤害就是"对抗成功后改资源"，类型用资源标识表达即可 | numbers §4.8 |
| SC-14 | 超线性伤害放大 | 参考实现加它是为了补偿被压扁的力量值；我们只要**别把力量压那么狠**就不需要——多一项隐式放大就多一个失控点 | numbers §4.8 |
| SC-15 | 死参数 | 参考实现的命中判定带一个从不使用的参数，还有多处**以为它有效**。参数要么生效、要么不存在 | numbers §4.8 |
| SC-16 | 照抄参考实现的经验曲线 | 它的衰减分支判的是**目标等级**而不是循环下标，30 级出现 249 → 1467 → 380 的 6 倍跳变——**是 bug 不是设计** | numbers §4.8 |
| SC-17 | 搬参考实现的代码 | 只取机制与数值设计；它不是依赖、不参与构建 | numbers 开头 |
