# 范围：明确不做

细则层。编号 `SC-xx`。

**非目标只放两样东西**：做了会违背[设计支柱](requirements.md)的、以及游戏里就是没有的。

**"暂时推迟"不在这里**——那是进度问题，不是游戏要什么。它们连前置条件一起记在 [decisions.md](../decisions.md) 的搁置项里。
