# 设计

**当前为空。** 设计要先讨论，定了才写进来——这里不存草稿、不存提案。

**边界**：这里回答"怎么做"——结构、模块、数据流、取舍。**不写**"要什么"（那属于 [requirements/](../requirements/README.md)）。

## 三个位置

| 位置 | 放什么 |
| --- | --- |
| 本目录顶层 | **与引擎无关**的模型：组件、系统、消息、数值。两条引擎线都必须实现它 |
| [bevy/](bevy/README.md) | 只有真的取决于 Bevy 的取舍 |
| [godot/](godot/README.md) | 只有真的取决于 Godot 的取舍 |

## 共同约束

- 每条设计都要引用它服务的需求条目（`REQ-xxx`）；引不出来，说明这条设计没有上游。
- 引擎无关的内容写顶层，别下沉到某条线里。
- 按**更小的部分逐步分解执行**：一个主题一篇文档，不写大而全的总设计。
