# L0 原子：组件与纯函数

自底向上的第一层。这里只有两件事：**存数值**、**算数值**。**没有系统**——所有推进都是纯函数求值，谁调用、什么时候调用，结果都一样。

数组件的判据：**单独拿出来，只靠自己（外加它自己的纯函数）就能把含义说清。**

## 空间

| 组件 | 字段 | 数值 | 为什么在 L0 |
| --- | --- | --- | --- |
| `GridPosition` | `x`、`z` | 整数格 | 一个坐标自己就能说清"在哪" |
| `Motion` | `from`、`to`、`started_at`、`ends_at`、`path` | 格 + 时间戳 + 格序列 | 一次位移自己就是一个完整事实 |
| `Speed` | 格/秒 | 实数 | 单个数就说清"多快" |

要点：

- **只存整数格。** 逻辑位置永远落在合法格上，不存在"卡在格与格之间"的状态，所以"走一半按了技能"这类问题有确定答案。
- **不存插值位置。** 视觉位置是算出来的（见 `position_at`），不是存的——存了就会与时间轴打架。
- **高度不是位置的一部分。** `GridPosition` 只有 `(x, z)`，地面高度从地形查出来，是派生值。以后要高低差，只改那个查表函数。
- `Motion` 的 `from == to` 就是静止。**没有单独的"是否在移动"标志位**——那会多出一个可能与位置矛盾的真相。

## 数值

| 组件 | 字段 | 说明 |
| --- | --- | --- |
| `Pool` | 种类、当前值、上限、回复 | HP / 法力 / 行动 / 反应都是池，只有种类不同 |
| `Stats` | 基础值、修饰符、最终值 | 键是词汇 ID，加一条属性不改代码 |
| `Status`（独立实体）+ `AttachedTo`（关系） | 种类、剩余时长、层数 | 状态是实体，不是宿主身上的一个字段 |
| `ActorState` | 已挂状态的同帧快照 | 只为"这一帧就能读到刚挂上的状态"存在 |

要点：

- **全程实数，不取整。** 上限、下限、见底语义都是池自己的字段——引擎不知道"哪个池是命"，那是内容语义。
- **修饰符每帧整批重建。** 所以到期不需要"清理"消息，也不会残留半份旧修饰符。
- 一个角色的数值只有一份真相：池有唯一写入口，属性有唯一定义点。

## 身份（三条正交轴）

| 组件 | 回答的问题 | 形态 |
| --- | --- | --- |
| `ActorRole` | 谁听输入、谁自己决定（玩家 / AI） | 固定枚举 |
| `Faction` | 谁打谁 | 固定枚举 |
| `ActorTags` | 它是什么东西（亡灵 / 构装 / 野兽……） | 词汇 ID 集合 |

三条轴正交，"玩家侧的亡灵"因此是**正常组合而不是特例**，不需要任何特判。

判据是**带不带规则**，不是"是不是标签"：阵营带引擎级规则（谁敌视谁），所以固定；特性不带规则，所以可以靠数据加。

## 意图

| 组件 | 说明 |
| --- | --- |
| `DecisionSlot`（一对一关系） | 怪物"打算做什么"。**槽空 = 没有这个组件**，不是"持有一个空值" |
| `HasThreat` / `PendingThreat` | 谁威胁了谁，以及尚未兑现的威胁 |

"打算做什么"必须能被外部读到——反制窗口就建立在"敌人正在前摇"这件事**可被观察**之上。换意图时旧意图必须被显式处理，别让它悄悄堆积。

## 世界

| 组件 | 说明 |
| --- | --- |
| `ChunkPos` | 区块坐标，32³ 一块 |
| `VoxelStore` | 改动表：只存**被改过**的体素 |
| 程序化层 | 确定性函数，**不存储**；查询先查改动表，未命中再算 |

世界数据是纯数据 + 纯计算：它**不认识素材、纹理、渲染**。格 ↔ 世界坐标的换算只有一份实现，渲染层不许自己发明——否则改区块尺寸时会漏改，画面与数据错位。

## L0 纯函数

原子层没有系统，推进靠这些纯函数：

| 函数 | 作用 |
| --- | --- |
| `position_at(motion, now)` | 格 → 视觉坐标。`t = clamp((now - started_at) / (ends_at - started_at), 0, 1)`，在 `from → to` 间插值；**高度只在这里加一次**（从地形查） |
| `ground_of(world, x, z)` | 这一格的地面高度 |
| `voxel_at(world, pos)` / `set_voxel(world, pos, v)` | 读 / 写体素；写只落改动表 |
| `raycast(world, origin, dir, max)` | 逐格步进（DDA），返回命中格与命中面法线 |
| `to_world(grid)` / `to_grid(world)` | 格 ↔ 世界坐标的**唯一**换算，渲染层只能调它 |
| `scale(值, 锚点, 幂)` | 过两锚点拟合数值曲线，**锚点处的值精确命中** |
| `rescale(值, 区间)` | 分段线性压缩，只压不设 |
| `contest(攻方, 守方, 判据)` | 对抗判定求值；**全游戏唯一的随机点** |
