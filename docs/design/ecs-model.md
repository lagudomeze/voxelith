# 游戏是什么：ECS 视角

本文只用 ECS 语汇（组件 / 系统 / 消息 / 全局数据）描述这个游戏，不含引擎与语言细节。引擎实现分两条线：[bevy/](bevy/README.md) 与 [godot/](godot/README.md)；本文是它们共同的上游，两条线都必须实现它。

> **术语约定**：**池**指 HP / 法力 / 行动 / 反应这类"有上下限、会被消耗的量"。ECS 里的全局单例数据叫**全局数据**。两者不混用——旧实现把池叫 `Resources`，和 ECS 的全局资源撞名，换掉了。

## 一句话

**体素世界里，玩家与怪物在同一张格子上按时间轴轮流行动；玩家不操作时时间冻结，玩家一操作怪物才动；怪物"打算做什么"是可见的，玩家可以抢先反制它。**

三个机制不可拆：**格子空间**、**时间轴（谁在动）**、**可观察的意图**。缺任何一个，这个游戏就不是它了。

## 纯数值内核

游戏状态 = **一组数值 + 一个时间轴**。渲染只是把这些数读出来画，不参与任何计算。四条断言：

1. **数值只有一条写入路径。** 所有变更都走同一组受控原语；"谁把血量改了"必须永远能答。
2. **只有一个随机点。** 随机只发生在对抗判定里；同样的输入必然得到同样的结果。
3. **位置是时间的纯函数。** 每帧从 `f(现在)` 重算，不累加；时间被冻结或加速时不留下漂移。
4. **内容即数据。** 技能、状态、池、怪物、特性都由数据描述；加一类内容不改代码。

## 三层

| 层 | 有什么 | 没有什么 |
| --- | --- | --- |
| **L0 原子** | 只有数据与纯函数。一个组件单独拿出来，只靠自己就能把含义说清 | 没有系统 |
| **L1 行为** | 系统 + 消息。需要多个原子同时在场才成立 | 不生成渲染实体、不碰素材、不读文件 |
| **L2 表现与交互** | 渲染、UI、输入。只读 L0/L1 的数据 | 不直接改数值，只能发请求消息 |

**L0 归谁判据**：把组件单独拿出来，只靠自己（外加它自己的纯函数）能不能把含义说清？能 → L0；要靠别的组件在场才有意义 → 那是 L1 的行为，不是 L0 的组件。

**L0 没有系统，是刻意的**：原子的推进一律是纯函数求值（"位置 = f(时间)"），而不是"每帧跑一个系统去改它"。这样同一份原子能在没有渲染、没有文件系统、没有调度器的环境里被求值、被测试。清单见 [atoms.md](atoms.md)。

## 系统之间只通过消息

规则：**系统不调用系统，只发消息；需要顺序就显式排，不靠约定。**

| 消息 | 谁发 | 谁收 | 承载什么 |
| --- | --- | --- | --- |
| 移动请求 | L2 交互 | L1 移动 | "我要走这条路"——只塞路径，走不走、怎么走由 L1 决定 |
| 技能请求 | L2 交互 / UI | L1 行动 | "对某目标用某技能" |
| 行动到达释放点 | L1 行动 | L1 对抗 | 一次技能动作到了结算时刻 |
| 对抗结算 | L1 对抗 | L1 效果 | 判定结果（成功 / 失败 / 暴击）与差值 |
| 效果应用 | L1 效果 | L1 池、L1 状态 | **唯一的世界突变通道** |
| 池变更 | L1 池 | L1 相位、L2 表现 | 某个池从多少变到多少，含"见底" |
| 状态变更 | L1 状态 | L2 表现 | 挂上 / 到期 / 被净化 |
| 意图变更 | L1 决策 | L1 行动、L2 表现 | 怪物"打算做什么"——反制窗口靠它开 |
| 威胁变更 | L1 行动 | L1 相位 | 谁威胁了玩家 → 要不要开反制窗口 |
| 相位变更 | L1 相位 | 全部（含 L2 停 / 启动画） | 结算中 / 等输入 / 等反制 |
| 体素变更 | L1 世界 | L2 渲染 | 哪一块变了——唯一的重建触发通道 |

> 这是描述，不是实现。引擎若没有"消息"这一物，等价物是"事件 + 显式订阅"。约束不变：**不跨系统直接调用，不共享可变状态。**

## 世界怎么变成画面

一切表现都从同一份数据推导，并且**状态与通知分离**：

- **消息决定"播什么"**：起特效、抖一下、弹个条。
- **组件决定"播多久"**：动画、渐隐、读条都是"数据 + 每帧推进"，不进消息。

这条分离是跨帧表现不丢帧、不粘滞的前提。

## 交互与 UI：分开描述

**交互（输入）只做两件事**：把物理输入翻译成请求消息（塞路径、发技能请求），以及选目标。它**不判断能不能走、能不能打**——那是 L1 的事。

**UI 只读**：读池、属性、状态、相位、当前可做的动作，画出来。它**不发世界变更**；要变更就发请求消息。

两者都不写数值。
